# Publications de Mycyl

Ce dépôt ne contient que les publications de Mycyl, le logiciel de supervision de [Lichenia](https://lichenia.fr) : l'installateur Windows de chaque version, ses fichiers de mise à jour et leurs signatures. Il ne contient aucun code source.

- Chaque mise à jour est signée par la clé de mise à jour de Lichenia (minisign, identifiant `7A53484AA053431D`). Mycyl refuse toute mise à jour qui ne l'est pas.
- L'empreinte SHA-256 de chaque installateur est donnée avec sa publication.
- Les publications sont faites par la chaîne de publication de Lichenia, jamais à la main.
